# ai-company-pool

AI 求职「目标公司池」：Markdown 源数据 + 可视化 HTML。  
优先赛道：Coding / 研发 Agent · 办公效率 Agent · 客服销售 Agent · 电商运营 AI。

## 文件

| 路径 | 用途 |
|------|------|
| `20-信息/目标公司池.md` | 权威表格（Automation 每周追加） |
| `20-信息/目标公司池.html` | 可筛选可视化页 |
| `AUTOMATION.md` | Cursor 定时 Agent 指令 |

本地对照副本也会同步到 `~/Documents/job-search/20-信息/`。
